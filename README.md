# Ula'tek Heroic: BL al pull o al corazón

Análisis del [reporte público de Warcraft Logs del 7 de octubre de 2026](https://es.warcraftlogs.com/reports/3wVANaJLZ9GdcnhT) de Räge Quit.

**Conclusión:** el modelo favorece conservar BL para la primera exposición del corazón. En los 12 pulls del reporte, BL se usó alrededor del minuto 2; no hay un pull con BL al inicio para hacer una comparación experimental directa.

- [Abrir el informe completo con gráficos](index.html)
- [Descargar los datos en CSV](datos_bl_ulatek_2026-10-07.csv)

El corazón recibe 100% de daño adicional durante 20 segundos. Los valores de daño al corazón del informe **ya incluyen** ese multiplicador. El modelo compara el daño medido durante la apertura y la primera exposición del corazón en los pulls #6, #10 y #11, y presenta escenarios para distintos aumentos de daño efectivo de BL. El 30% de celeridad de BL no se trata como un 30% fijo de DPS.

Para ver el informe sin conexión, descargá `index.html` y abrilo en un navegador. También se puede imprimir o guardar como PDF desde el navegador.
